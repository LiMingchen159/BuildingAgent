# 功能文档页面模板

[English](../en/page-template.md) | [开发者文档首页](README.md)

> 代码基线：`main@af44ff15`。复制此结构时必须同时创建或更新英文镜像页。

## 1. 状态与代码基线

使用 `已实现 / 部分实现 / 规划中 / 外部能力`，并给出核对过的提交、入口文件和事实边界。

## 2. 功能目的及边界

说明解决的问题、明确不负责的事项，以及目标架构和当前实现的差异。

## 3. 用户入口和关键源码入口

列出 Web、CLI 或 API 入口，以及可验证的源码、类型和路由位置。

## 4. 正常数据流

按请求、处理、响应和事件顺序描述主路径。

## 5. 数据、状态及持久化

区分权威数据、用户文件、可重建索引、缓存和外部系统状态。

## 6. 权限与项目隔离

说明鉴权、角色、项目作用域及越权防护。

## 7. 错误、降级及外部依赖

列出错误封装、重试/回退行为和可选或必需的外部服务。

## 8. 扩展方法

指出新增实现时应复用的注册表、接口、目录和验证方式，不承诺未实现能力。

## 9. 对应测试

给出具体测试文件和推荐命令；测试结果必须和命令执行环境一起记录。

## 10. 已知限制及关联文档

列明契约差距、技术债和相关架构/FDD/开发页面。
